# CivSlice

**文明切片** — 用科学方法，按时间线展示一个国家/文明在十个维度上的定性快照。

在线原型：**https://jk9988610.github.io/CivSlice/**

## 项目定位

CivSlice 是「多维文明历史可视化」的实现仓库。原始构想与方法论记录保留在 [Talk](https://github.com/jk9988610/Talk/blob/main/docs/07-projects/2026-08-12-多维文明历史可视化.md) 想法文档站。

观看历史叙事时，王朝更替与人物故事往往掩盖了文明在多个维度上的整体状态。CivSlice 尝试用结构化、可标注可信度的方式，呈现「某一时刻文明长什么样」——不是精确统计，而是有证据约束的定性概括。

## 十维框架

| # | 维度 | 说明 |
|---|------|------|
| 1 | 地理气候 | 空间、气候、地缘约束 |
| 2 | 资源能源 | 可开发的自然要素 |
| 3 | 技术能力 | 工具、方法、知识水平 |
| 4 | 生产组织 | 农业/手工业/劳动分工 |
| 5 | 经济交换 | 贸易、货币、分配 |
| 6 | 政治制度 | 国家形态、治理、官僚 |
| 7 | 军事国力 | 战争能力、疆域变动 |
| 8 | 社会文化 | 宗教、艺术、教育、阶层 |
| 9 | 日常生活 | 食物、医疗、居住 |
| 10 | 历史记忆 | 自我叙述、史书、神话 |

## 科学方法

每条维度记录附带可信度分级：

| 级别 | 含义 |
|------|------|
| `documented` | 考古实物或 contemporaneous 文献 |
| `inferred` | 基于相邻证据的合理推论 |
| `speculative` | 假说性判断，待检验 |
| `absent` | 证据不足，不做判断 |

核心原则：

- 考古与文献优先；推断须标注并说明逻辑链
- **禁止以今证古** — 现代发展水平不能反推古代等级
- 承认历史断裂（亡国、改朝、殖民、灾害）
- 等级 1–5 为文明内部相对概括，非跨文明精确排名
- **无证据维度留空**，优于强行填充

## 当前内容

首国探索：**中国**，8 个时间点快照（公元前 2000 二里头 → 公元 1950）。

交互原型位于 `site/` 目录，包含时间轴滑块、十维雷达图、维度卡片与方法论侧栏。
